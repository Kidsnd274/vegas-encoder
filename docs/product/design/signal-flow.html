Vegas Encoder design round 2: the chosen direction

Signal Flow

See the path from the VEGAS timeline to the file as a fixed diagram. VEGAS feeds the video and audio encoders, they join in the container, and the container writes the file. Selecting a node opens its settings below, next to the command.

The memorable thing: wires that thin where precision is lost. Wire thickness is bit depth, and an amber pip marks every pixel-format conversion, so “10-bit becomes 8-bit here” is visible at a glance.

Changed after the owner’s review (2026-10-12):

  • Modes are called Basic and Advanced.
  • The desktop diagram is about a third shorter. The VEGAS popup uses a one-row strip.
  • Size and quality moved behind the File node, with a length you can type.
  • No “All options” list. Anything without a control goes in Extra arguments, which is still checked against FFmpeg’s options.
  • A dark theme that follows Windows.
  • A small render progress window (S6), plus a status line in VEGAS’s own render dialog if the VEGAS test allows it.

S1

Presets and Basic editor

Pick a preset, follow the signal from VEGAS to the file, and set each stage where it happens.

Try: switch Bit depth between 8-bit and 10-bit, choose ProRes, turn audio off, type an unknown option in Extra arguments, or pick FFmpeg 8.0 LGPL in the header.

S1

File node: size and quality

The estimate appears only here. Type a length to see the total; the rate per minute doesn’t need one.

Try: change the length, then select the video encoder and move the quality slider. The File node keeps the estimate one click away.

S2

Advanced mode

Write the whole command. The diagram reads it back, so conversions stay visible.

Try: change -pix_fmt yuv420p10le to yuv420p and watch the wire thin, or delete {output}. Suggestions open after - and with Ctrl+Space.

S3

VEGAS popup

Edit the render template VEGAS is about to use, compare it with the library, apply and get back to rendering. The diagram is a one-row strip.

S4

FFmpeg

See which FFmpeg renders, what it can encode on this PC, and why something isn’t available.
