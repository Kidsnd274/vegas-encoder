Installer: VEGAS integrations page

Two layouts for the VEGAS integrations page. Option A, the chosen one, is what setup/includes/hosts.iss implements: Inno's checklist with one row per VEGAS version, plus the folder of the selected row. Both are shown in Update mode (0.1.7 installed, setup 0.1.8). Setup uses WizardStyle=modern dynamic polar, so it follows the Windows light/dark setting.

The rows are clickable: tick or untick to see each status, select a row to see its folder, and press Next with nothing ticked to see the warning. Colours approximate Inno's Polar style and are not a screenshot. "VEGAS Pro 2027" is an example of a future supported version. Behaviour: docs/INSTALLER.md, VEGAS integrations.

Option A: checklist and selected folder (chosen)

Option B: one block per VEGAS version (not chosen)

Every folder is visible with its own Change button. Not chosen: in Inno each row would be separate hand-built controls, and only about four rows fit without a scrolling area.
