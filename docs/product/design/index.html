Round 1: eight directions

Eight ways to shape the same product: the desktop app, the shared editor in Guided and Command modes (renamed Basic and Advanced in round 2), the VEGAS popup, and the FFmpeg page. They all use the same content and live command compiler (shared/model.js), so the differences you see are design differences.
