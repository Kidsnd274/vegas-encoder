Vegas Encoder design directions

Eight ways to shape the same product: the desktop app, the shared editor in Guided and Command modes, the VEGAS popup, and the FFmpeg page. They all use the same content and live command compiler (shared/model.js), so the differences you see are design differences.

Open a direction to use it; most controls are live. Mixing is expected: note the parts you'd keep from each.
