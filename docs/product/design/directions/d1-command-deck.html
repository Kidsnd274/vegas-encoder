Command Deck

The live FFmpeg command is the interface. Every group of arguments is a handle on the controls that produce it, so the command a power user trusts is also the map a beginner follows.

The memorable thing: the tokenized command at the top. Click a group to open its controls, hover a control to light up the arguments it writes, and switch to Command to edit the same deck as text.
