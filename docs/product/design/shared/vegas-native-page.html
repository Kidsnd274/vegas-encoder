Native page in VEGAS's Custom Settings dialog

Shared by every design direction. Gated on adapter milestone A5. Plain Win32 controls in the DLL: a summary, Edit settings… to open the Vegas Encoder window, and a quick Load preset menu.

Behaviour notes

  • Edit settings… writes a session file and starts VegasEncoder.exe --edit-session, owned by this dialog. The page shows the open state within 100 ms; the editor window should appear within about a second.
  • Apply in the editor returns settings to this page. The template changes only when VEGAS applies the page (OK), following the semantics measured in adapter milestone A6.
  • Load preset copies a library preset into the template without opening the editor. The origin line updates to that preset and revision.
  • "Edited in VEGAS" appears when the template differs from its origin revision. "Library has a newer revision" appears when the preset has moved on; updating happens in the editor, where the differences are shown.
  • Nothing here reads the library during a render. The template holds a complete copy of the settings.
